# Orbit Lab · 轨道实验台

目标：无需指定父天体，以三维牛顿引力自然产生轨道。原生命令行和浏览器实验台使用同一份 Rust 物理内核。

网页首页打开太阳系的全屏地球近景。点「播放」推进 JPL DE440 初值的十体场景，底部可在 `0.01×` 至 `4×` 间调整倍速，或点「复位」回到已应用的初值并暂停。按住右键或 Shift 加左键拖动可平移视野，触屏用双指同向滑动。点「全景」查看整个太阳系，远景定位点按半径区分大小。对准天体滚轮放大，或以天体为中心张开双指，可拉近查看模型。点「视图 → 地月轨道」查看月球相对地球的轨迹。左上角的场景菜单提供「太阳系」「三体星系」「自定义实验」和实验文件操作。[浏览器实验台](./M3_WORKER.md)

选择「三体星系」进入行星近景，点「全景」可观察大小各异的三颗太阳交错运行。行星先绕 B 公转，约在模拟时刻 `39` 转而绕 A，之后回到 B。三颗太阳共同照亮地表、云层和大气，场景默认持续推演。[三体星系示例](./M3_WORKER.md#三体星系示例) · [宣传短片复现](./M3_WORKER.md#三体星系宣传短片)

选择「自定义实验」进入空坐标系。打开「天体库」可拖动天体，也可先轻点卡片再选落点。场景中的天体可按住拖动，松开后能在参数面板精调位置、半径、密度和初速度。点「应用初值」使用调整后的初值开始推演。「参数 → 推演」可设步长与可选的总步数。[放置与编辑](./M3_WORKER.md#自定义引力实验)

## 快速开始

### 浏览器实验台

安装 Rustup、Node.js 24、Python 3 和支持 WebGL 2 的浏览器，在仓库根目录执行以下命令。

```sh
rustup toolchain install 1.85.1 --profile minimal --target wasm32-unknown-unknown
sh scripts/build-m3.sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory target/m3-site
```

浏览器打开 `http://127.0.0.1:8000/` 即可开始推演。安装 Chrome 后可用 `node scripts/verify-m3.mjs target/m3-site` 运行浏览器回归。[浏览器实现与验收](./M3_WORKER.md)

### 原生命令行

使用 Rust 1.63 或更新版本，在仓库根目录执行以下命令。

```sh
cargo test --locked
cargo run --locked --release > binary.csv
```

输出等质量双星一个周期的质心系轨迹。两条轨迹应关于原点对称；时间列以模拟单位表示，不是秒。实验设 G、双星总质量和初始间距都为 1，解析周期为 2π。测试将步长减半，检查位置误差约缩小四倍。

## 当前边界

内核在 CPU 上使用 f64、直接逐对求和及 leapfrog，单步 O(N²)。双星实验以固定步长推进，三体飞掠可显式选择近遇变步长。物理模型限于正质量点天体的牛顿引力。重合位置返回错误，不应拿当前步长推演近掠而不复算。

## 验证与下一步

M2 已记录[串行 CPU 性能基线](./M2_BASELINE.md)：等质量双星和 64 体短弧在解析误差门槛内分别测一次求力与完整一步；连续推进现复用已提交状态的终点加速度，同机前后对照见[缓存实验](./M2_ENDPOINT.md)。

三体飞掠实验用独立参照检查近遇后的出射方向和三维轨迹误差。四组初值的 Release 计时在同一误差预算下对照固定步长与近遇变步长，完整推进包含选步开销。普通 `cargo test` 会读取仓库里的参照数据。[三体飞掠实验与复现命令](./FLYBY_BASELINE.md)

双星解析比较和非共面四体旋转实验的复现命令、误差指标与验收门槛见 [M0 数值基线](./M0_BASELINE.md)。连续推进时用 `Simulation::new(&initial)` 创建一次模拟，循环调用 `step(dt)`，通过 `bodies()` 和 `time()` 只读观察已提交的状态和时刻。失败回滚与固定规模零分配的验证范围见 [M1 执行单](./M1_EXECUTION.md)。模块职责、性能验收标准以及 M0–M3 路线见[引擎架构与迭代计划](./ARCHITECTURE.md)。
